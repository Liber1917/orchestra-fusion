How It Works
一句话驱动全流程
Orchestra Fusion 会在后台自动分析任务、构建 DAG、分配角色、派发子代理、监控进度、汇总报告。
👤 用户: "用 agent 团队分析 vitfly 代码库并给出架构改进建议" 🚪 Intent Gate: Mixed · Medium · 风险: 跨语言分析 📋 Plan: Wave 1: Scout:调研代码结构 Wave 2: Builder:架构分析报告 Wave 3: Reviewer:审查 👤 用户确认 → 🚀 Dispatch → 📊 Monitor → 📝 Report → ✅ Done
ATO · 角色+审查 DevFleet · DAG+看板 dmux · 并行模式 OMO · 熔断+并发
Capabilities
核心能力
🎯

意图门禁

自动判断任务类型/复杂度/风险，简单任务降级直接执行，复杂任务启动团队编排。

📋

DAG 规划

分析任务依赖，构建有向无环图。支持 auto_dispatch：前置完成自动触发后续。

⚡

7 种并行模式

Research+Build / Multi-Build / Review Pipeline / Fix+Verify / Escalation / Interview-Mode / Autonomous Loop。

🛡️

生产级防御

Slot 并发控制(5槽位/Key) · 熔断器(20次重复/4000次上限) · 陈旧检测(45/60min)。

🚪

7 道质量门禁

Intent → Pre-Plan → Plan → Handoff → Review → Loop → Ship，每一步都有检查和人在回路。

🌐

三平台适配

WorkBuddy 原生支持 · Claude Code 降级策略 · OpenCode 降级策略。

🔄

自主循环

Report 后 Agent 自主判断是否继续。不是外部定时调度，而是评估结果后智能决策。
