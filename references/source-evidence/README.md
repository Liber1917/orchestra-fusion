# Source Evidence — 源方案证据归档

> 此目录用于存放四个源方案的 SKILL.md 关键段落摘录，
> 供 future audits 或独立核验时使用。

## 目录约定

每个源方案一个 `.md` 文件，格式：

```
ato-evidence.md          — Agent Team Orchestration
devfleet-evidence.md     — Claude DevFleet
dmux-evidence.md         — dmux-workflows
omo-evidence.md          — oh-my-opencode
```

## 内容格式

每个证据文件包含：

1. 源 skill 的基本信息（名称、版本、获取时间）
2. 按声明分类的原文摘录（用 `>` 引用块）
3. 摘录对应的 SKILL.md 段落位置
